# Feature Development

When implementing a new feature:

1. Understand requirements.
2. Identify affected modules.
3. Reuse existing code.
4. Create backend first.
5. Create frontend second.
6. Connect APIs.
7. Handle loading states.
8. Handle errors.
9. Verify responsiveness.
10. Verify edge cases.

Deliver:
- routes
- controller
- service
- model changes
- frontend integration
